# Rebrand: STRATIQ AI → VELQORIN.ai

This was a rename, not a rebuild. Routes, APIs, database, authentication, engines and user data are unchanged.

## What changed

- **Visual identity:** new original geometric "V" mark (`Logo.tsx`, `src/app/icon.svg`), wordmark `VELQORIN` + violet `.ai`, favicon (`favicon.ico` 16/32/48), Apple touch icon, 192/512 PNG icons, and a 1200×630 social preview (`opengraph-image.png`, `twitter-image.png`, with alt text). The existing midnight-navy / violet / cyan design system is untouched.
- **SEO and social:** default title `VELQORIN.ai — Intelligence Beyond Prediction`, title template `%s | VELQORIN.ai`, meta description, Open Graph and Twitter tags, `Organization` JSON-LD (name, alternate name, slogan, description), web app manifest (`manifest.ts`). No performance statistics or unverified claims were added.
- **Copy:** every user-facing reference on the landing page, header, footer, early-access form and consent text, about, pricing, how-it-works, domain pages, login/signup, dashboard (search label, titles, overview), admin (title template), reports, exports, assistant prompt, and the API's OpenAPI title.
- **New branded pages:** `not-found.tsx` and `error.tsx` (the app previously used Next's defaults).
- **Tests:** the Playwright suite now asserts the brand on every public page and every dashboard page (title, visible text and page source never mention the old name), checks the manifest, icons and social image are served, and checks the product names in both navigations.

## Intentionally unchanged (technical identifiers)

Renaming these would break sessions, integrations or deployments for no user-visible benefit.

| Identifier | Why it stays |
|---|---|
| Python package `stratiq` and its module names | Imported across the API, tests and Vercel function |
| Cookies `stratiq_session`, `stratiq_admin`; localStorage `stratiq_adv` | Renaming would sign every user out and reset preferences |
| JWT issuer `stratiq-web` | Both the web app and API must agree; changing it needs a coordinated deploy |
| Postgres setting `stratiq.allow_prediction_delete`, databases `neondb` / `stratiq_dev` | Database-level names |
| Export format id `stratiq-workspace-export` | A machine-readable format identifier consumers may match on |
| Test account domain `@stratiq.test` | Pattern used by the e2e teardown |
| `package.json` name, Vercel project `stratiq-ai`, GitHub repo `oawill/stratiq-ai`, `.vercel/` | Existing deployment and hosting resources |
| Environment variable names | No renames needed |
| `supabase/migrations/0002_app_core.sql` header comment | An already-applied migration; editing history is avoided |

The two remaining uppercase mentions of the old name in the repository are the README's "formerly named" note and that migration comment.

## Not applicable / not found

- **Email templates:** none exist (the app sends no email).
- **Legal pages:** none exist (no terms or privacy page). They should be written, and reviewed by a lawyer, under the new name; none were invented here.
- **Stored data:** every text and JSON column in the database was searched; none contains the old name, so no data migration was needed.
- **Loading screens:** the only loading states are plain "Loading…" text with no brand.

## Deploying under https://velqorin.ai — manual steps (nothing here was changed in live hosting)

1. **Confirm you own or can register `velqorin.ai`** (and check trademark availability for "VELQORIN"; this is not legal advice).
2. In the Vercel project, **add the domain** `velqorin.ai` (and `www`), then create the DNS records Vercel shows at your registrar.
3. Set production environment variables, then redeploy:
   - `NEXT_PUBLIC_SITE_URL=https://velqorin.ai` (canonical URLs, sitemap, Open Graph image URLs)
   - `PY_API_URL=https://velqorin.ai` (the web app calls its own Python function; currently the `vercel.app` address)
4. Optionally redirect the old `stratiq-ai.vercel.app` address to the new domain.
5. After DNS is live, run the suite against it: `E2E_BASE_URL=https://velqorin.ai E2E_DATABASE_URL=<production url> npm run test:e2e`.
6. Check the social preview with the platforms' own link debuggers (they cache previews), and submit the new sitemap to search consoles.
7. Optional, only if you want the internal names to match: rename the Vercel project and GitHub repository. This is cosmetic and unrelated to the domain.
